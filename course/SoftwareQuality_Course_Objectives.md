# Purpose and learning objectives
The subject element contains and deals with key methods and techniques for achieving software quality both in connection with new development and maintenance, including concepts and techniques for the design and construction of testable systems. Furthermore, design and implementation of systematic testing on larger systems, including the establishment of automated testing.

## Knowledge
The student has knowledge of:
• essential test strategies and models and their role in system development
• ensuring software quality as an integral part of a development project
• different test types and their application

## Skills
The student can:
• design testable systems
• ensure traceability between system requirements and software testing at all levels
• use different test forms
• apply different criteria and metrics for software testing
• apply techniques and tools for automating testing

## Competences
The student can:
• participate in the development and adaptation of methods and techniques for ensuring software quality
• collaborate with others in relation to software quality
• identify own learning needs in relation to software quality
